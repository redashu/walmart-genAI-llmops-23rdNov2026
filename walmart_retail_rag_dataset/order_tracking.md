# Order Tracking and Delayed Orders

Document ID: RET-001
Category: Orders
Version: 1.0
Status: Synthetic training content

## Checking Order Status

Customers can check an order's latest status from the order details page using the order number associated with their account.

Typical order statuses include:
- Order received: The order has been submitted.
- Processing: The order is being prepared.
- Shipped: The package has left the fulfillment location.
- Out for delivery: The package is with the delivery service.
- Delivered: The delivery service has marked the package as delivered.
- Delayed: The expected delivery date has changed or the shipment is behind schedule.

## Delayed Orders

If an order is delayed:
1. Check the latest tracking event.
2. Confirm the current estimated delivery date.
3. Check whether the carrier has posted an exception or revised delivery estimate.
4. If tracking has not changed for an extended period or the revised date has passed, contact customer support for investigation.

Do not promise a new delivery date unless it is shown in the current order or carrier information.

## Tracking Has Not Updated

Tracking events may not appear immediately after a package moves between facilities. If no new event appears, ask the customer for the order number and refer the case to support for a shipment trace when appropriate.

## Order Marked Delivered but Not Received

Ask the customer to:
- Check the delivery location and nearby safe places.
- Check whether another household member or authorized recipient accepted it.
- Review any delivery photo or carrier note, if available.

If the package is still missing, create or escalate a missing-delivery support case.

## Information Required for Assistance

Request only the information needed to locate the order:
- Order number
- Account email or other approved verification detail
- Brief description of the issue

Never ask customers to provide passwords, full payment card numbers or one-time security codes.
